# 나의 첫 번째 AI 계산기

바이브코딩 수업에서 AI의 도움을 받아 만든 웹 계산기입니다.

## 계산기 실행하기

https://dbqlsdn.github.io/my-calculator/

위 주소를 열면 PC와 모바일 브라우저에서 사용할 수 있습니다.

## 주요 기능

- 숫자 두 개를 입력하여 더하기, 빼기, 곱하기, 나누기
- 계산 결과 표시
- 0으로 나누는 경우 오류 안내

## 사용한 기술

- HTML: 화면의 기본 구조
- CSS: 색상과 디자인
- JavaScript: 계산과 버튼 동작

## 학습한 내용

- GitHub 저장소 만들기
- 파일 업로드와 커밋
- GitHub Pages로 웹 배포
- 변경 기록 확인과 제목 복원
